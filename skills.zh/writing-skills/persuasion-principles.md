# 技能设计中的说服原则

## 概览

LLM 会像人类一样响应说服原则。理解这套心理机制，有助于你设计出更有效的技能，不是为了操控，而是为了确保关键实践即使在压力下也能被遵守。

**研究基础：**Meincke 等人（2025）用 28,000 次 AI 对话测试了 7 条说服原则。说服技巧让遵从率翻了一倍多（33% → 72%，p < .001）。

## 七项原则

### 1. 权威
**是什么：**对专业能力、资质或官方来源的服从。

**在技能中的作用：**
- 命令式语言：`YOU MUST`、`Never`、`Always`
- 不容商量的表述：`No exceptions`
- 消除决策疲劳和自我合理化

**何时使用：**
- 需要纪律约束的技能（TDD、验证要求）
- 安全关键实践
- 已经成熟的最佳实践

**示例：**
```markdown
✅ 先写代码再写测试？删掉，重来。没有例外。
❌ 在可行时考虑先写测试。
```

### 2. 承诺
**是什么：**与先前行为、声明或公开承诺保持一致。

**在技能中的作用：**
- 要求公开宣布：“声明正在使用这个技能”
- 强制明确选择：“选 A、B 还是 C”
- 使用追踪：用 TodoWrite 记录清单

**何时使用：**
- 确保技能真的被遵守
- 多步骤流程
- 责任机制

**示例：**
```markdown
✅ 当你找到一个技能时，你 MUST 宣布：`I’m using [Skill Name]`
❌ 让你的协作方知道你正在用哪个技能也行。
```

### 3. 稀缺性
**是什么：**由时间限制或可用性有限带来的紧迫感。

**在技能中的作用：**
- 时间约束要求：`Before proceeding`
- 顺序依赖：`Immediately after X`
- 防止拖延

**何时使用：**
- 需要立即验证的要求
- 时间敏感的工作流
- 防止“我待会儿再做”

**示例：**
```markdown
✅ 完成任务后，立刻请求代码审查，然后再继续。
❌ 你可以方便的时候再审查代码。
```

### 4. 社会认同
**是什么：**顺从他人做法或“正常标准”。

**在技能中的作用：**
- 普遍化表达：`Every time`、`Always`
- 失败模式：`X without Y = failure`
- 建立规范

**何时使用：**
- 记录通用实践
- 提醒常见失败
- 强化标准

**示例：**
```markdown
✅ 没有 TodoWrite 跟踪的清单 = 步骤必然会漏。每次都这样。
❌ 有些人觉得 TodoWrite 对清单有帮助。
```

### 5. 一体感
**是什么：**共享身份、“我们感”、群体归属。

**在技能中的作用：**
- 协作语言：`our codebase`、`we’re colleagues`
- 共享目标：`we both want quality`

**何时使用：**
- 协作型工作流
- 建立团队文化
- 非层级式实践

**示例：**
```markdown
✅ 我们是一起工作的同伴。我需要你诚实的技术判断。
❌ 如果我错了，你大概应该告诉我。
```

### 6. 互惠
**是什么：**对收到帮助后要回报的义务感。

**在技能中的作用：**
- 要谨慎使用，容易显得在操控
- 在技能里通常并不需要

**何时避免：**
- 几乎总是（其他原则更有效）

### 7. 喜好
**是什么：**更愿意配合自己喜欢的人。

**在技能中的作用：**
- **不要用于遵从性**
- 会和诚实反馈文化冲突
- 会制造谄媚

**何时避免：**
- 用于纪律约束时，永远不要用

## 按技能类型组合原则

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 纪律约束型 | 权威 + 承诺 + 社会认同 | 喜好、互惠 |
| 指导/技巧型 | 中度权威 + 一体感 | 强权威 |
| 协作型 | 一体感 + 承诺 | 权威、喜好 |
| 参考型 | 只要清晰 | 所有说服手法 |

## 为什么有效：心理机制

**明确边界的规则会减少合理化：**
- `YOU MUST` 会消除决策疲劳
- 绝对化语言会去掉“这是例外吗？”这种问题
- 明确的反合理化设计会堵住具体漏洞

**实施意图会形成自动行为：**
- 清晰触发条件 + 必需动作 = 自动执行
- “当 X 时，做 Y” 比 “通常做 Y” 更有效
- 降低遵从的认知负担

**LLM 具有类人特征：**
- 训练数据里包含大量人类文本中的这些模式
- 在训练数据中，权威语言通常对应更高遵从
- 承诺序列（声明 → 行动）经常被建模
- 社会认同模式（人人都这么做）会建立规范

## 伦理使用

**正当：**
- 确保关键实践被遵守
- 创建有效文档
- 防止可预测的失败

**不正当：**
- 为个人利益操控
- 制造虚假紧迫感
- 用负罪感驱动遵从

**测试标准：**如果对方完全理解这种技巧，这是否仍然会服务于他们的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 说服的七项原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 用 28,000 次 LLM 对话测试了 7 项原则
- 使用说服技巧后，遵从率从 33% 提升到 72%
- 权威、承诺、稀缺性最有效
- 验证了 LLM 的类人行为模型

## 快速参考

设计技能时，问自己：

1. **它属于哪种类型？**（纪律、指导，还是参考）
2. **我想改变什么行为？**
3. **哪些原则适用？**（纪律型通常用权威 + 承诺）
4. **我是不是用太多了？**（不要把七项全用上）
5. **这是否合乎伦理？**（是否服务于用户的真实利益？）
